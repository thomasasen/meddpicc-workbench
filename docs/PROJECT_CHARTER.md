# Project Charter – MEDDPICC Toolbox

## Mission

MEDDPICC Toolbox macht einzelne Aufgaben aus komplexem B2B-Sales schneller, klarer und besser nutzbar.

Die Anwendung ist keine digitale MEDDPICC-Checkliste und kein CRM. Sie ist eine Sammlung fokussierter Microtools, die
jeweils eine konkrete Aufgabe lösen.

## Kernproblem

Viele MEDDPICC-Anwendungen scheitern daran, dass zuerst große Mengen strukturierter Deal-Daten gepflegt werden müssen,
bevor ein konkreter Nutzen entsteht.

Die Toolbox dreht dieses Verhältnis um:

**Aufgabe → minimale Eingaben → Logik → verwertbarer Output**

Nicht:

**vollständige Deal-Akte → Datenpflege → eventuell später ein Nutzen**

## Zielnutzer

Primär:

- Account Executive
- Strategic Account Manager
- Enterprise Seller
- Sales Leader im Deal Coaching

## Nutzenversprechen

Ein Verkäufer soll ein Tool öffnen können, ohne zuvor einen kompletten Deal anzulegen.

Kundenfähige Microtools sollen Outputs liefern, die sich direkt für folgende Situationen eignen:

- Kundentermin
- Workshop
- Präsentation
- Mutual Action Plan
- Business Case
- gemeinsame Go-Live- oder Closing-Planung

Interne Tools unterstützen Qualification und Coaching.

## Produktgrenzen

Nicht Teil des Core:

- CRM
- Pipeline Board
- Kontaktverwaltung
- E-Mail-Client
- Kalender
- generische Task-App
- verpflichtendes Backend
- verpflichtende Cloud
- verpflichtende AI
- globale Win Probability
- vollständige Opportunity-Pflege als Voraussetzung

## Später optional

Ein Deal Workspace kann später mehrere Microtool-Ergebnisse verbinden und Informationen wiederverwenden.

Wichtig:

> Der Workspace dient den Tools. Die Tools dienen nicht dem Workspace.

## Qualitätsmaßstab

Ein neues Microtool ist nur dann sinnvoll, wenn es:

1. eine echte Seller-Aufgabe löst,
2. weniger Eingaben verlangt als eine vollständige Deal-Modellierung,
3. einen klaren Output erzeugt,
4. fachlich nachvollziehbar ist,
5. eigenständig nutzbar bleibt.
